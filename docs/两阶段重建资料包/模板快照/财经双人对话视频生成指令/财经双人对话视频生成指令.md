# 《财报揭秘室》财经双人对话视频生成指令

> 用途：下次制作同类财经解读视频时，直接把下面的“步骤 A”和“步骤 B”发给 Codex。本手册把栏目视觉、节奏和验收要求固定下来；模板已提供主持人头像、Logo、默认背景音乐和音效。**TTS 音色使用当前获准配置或模板默认；只有在明确提供替换素材时，才替换模板内置音乐或音效。**

## 成片应有的观感

不是“整段旁白 + 静态 PPT”。而是两位主持人围绕一份财报逐层追问：

- 谁说话，谁高亮；另一位缩小、弱化。
- 对话框只展示本句的关键结论，不复述整段旁白；底部必须另有跟随 TTS 的句级字幕。
- 旁白说到哪里，数据和图形就出现到哪里；不能一进画面全展示。
- 章节标题先出现、先退出，再进入下一位人物的解说。
- 最后一条收束旁白开始时才进入全屏片尾；旁白结束的同一帧结束视频。

## 文本分镜说明

保留原稿的文字、标点与顺序，按自然句切分，不改写为新的男女对话。发言者标签属于原稿时保留；角色、章节、画面和音色的制作安排留到 Render。Analysis 不读取素材内容、不试听、不生成预览。

## 步骤 A：先确认文本分镜

```text
使用 video-pipeline 的文本分镜阶段，按原稿自然句输出可编辑文本列表。
目标：1920×1080 / 30fps、16:9 财经双人对话；不需要口型。
本阶段只确认文字，不输出画面、配音、字幕或技术时间轴。等待客户端确认完整文本列表后进入制作。
```

## 步骤 B：确认分镜后，让 Codex 执行

```text
按已确认的分镜执行并渲染预览。

配音：使用当前获准配置或模板默认音色，由 Codex 发起正式逐句 TTS；缺少必需配置时明确失败。制作内检查数字、专有名词和男女声辨识度，无需再次等待试听确认。

人物规则：复用模板 130×130 发言头像、64×64 待场头像的圆形裁切与固定位置；不能改成大半身像；观点卡只显示提炼后的短句，不能直接放完整旁白。
字幕规则：每个自然句可在语义停顿处拆成多条独立短句 TTS，每条最多 28 字、建议 12–24 字，拼接后保持原稿文字、标点与顺序。字幕使用各短句真实音频边界；禁止按比例切字幕；不做中文逐字对齐。拆句不增加 sceneId 或交付 MP4 数量。
音画规则：先从 `renderer/renderer-manifest.json` 读取栏目基线，复制到本期独立工程，并将 `assets/` 放入 `renderer/public/template-assets/assets/` 后实际复用；每条音频以真实时长写入内部 timeline；数据/卡片按句中信息分批出现；章节标题只占上一句结束后的转场空档；禁止标题和人物卡同屏。

先阅读模板《动效组件与内容适配说明.md》，复用既有动效；本期只编排章节、短句、图解数据和真实配音触发点。必须提供跨分镜 chapters，保留底部章节摘要、小标题高亮和全片进度条；不能按 sceneId 重置。参考片的摘要、人物观点与逐句字幕是三个独立字段。
渲染前运行清单中声明的 `sentenceAudioValidator`：校验短句拼接等于原稿、独立音频实际时长和字幕边界一致。Root 自动执行视觉参数校验；校验失败先修复数据，不得删除校验或缩小字体逃避限制。技术校验通过仍须对照参考视频检查实际画面和动效。
声音规则：默认使用模板内置背景音乐、章节音效、数据音效和风险提示音；对白优先。只有客户端明确提供替换素材时才替换；不使用无意义的收尾音或空白延时。
片尾规则：最后女声的栏目收束句开始时切入全屏主标动效，其他 UI 全部关闭；女声结束的同一帧结束视频，不加尾音、不留空白。

由 Codex 导出并检查人物切换、章节转场、片尾三个关键静帧，修复发现的问题后导出 MP4，不增加用户确认点。确认 N 句，交付 N 条含配音、字幕和画面的 MP4。
```

### Worker 两阶段任务的执行边界

客户端调用 Analysis 接口后，Codex 只返回可编辑的文本分镜；本阶段不调用 TTS、不生成媒体、不写技术帧。客户端确认并调用 Render 接口后，Codex 才自行决定何时调用 TTS、FFmpeg、Remotion 和审片脚本，并对最终成片效果负责。

Worker 只负责任务、模板冻结、隔离目录、状态和回调；它不决定镜头、字幕、动效、音乐、Remotion 工程或脚本调用顺序。

| 男主持人头像 | `assets/images/hosts/male-chief.png` | 男主持人发言时高亮置左；待场时缩小、弱化 |

| 数据音效 | `assets/audio/sfx/data-tick-soft.wav`、`data-tick-crisp.wav`、`number-counter-fast.wav` | 仅在关键数字、指标卡或曲线首次出现时使用，音量约 18% - 25% |
| 章节音效 | `assets/audio/sfx/section-tech-sweep.wav`、`headline-land.wav` | 仅填充章节标题入场/落定的转场空档，不延长章节 |

| 收束音效 | `assets/audio/sfx/closing-resolve.wav` | 可与最后一句和片尾动效并行，禁止在口播结束后额外延长视频 |

内置片头、片尾和参考成片仍位于 `assets/video/`。不要把历史案例的逐句 TTS 配音复用到新稿件；新稿件的正式口播由 Codex 在 Render 阶段发起，Worker 通过可信 TTS 工具代理执行。

## 分镜与排版：固定镜头语法

![开场钩子](assets/images/guide/01_hook.png)

| 镜头 | 画面规则 | 推荐时长 |
| --- | --- | --- |
| 开场钩子 | 单人抛出问题或 1 - 3 个反差数据；先制造问题，不先解释 | 8 - 15 秒 |
| 栏目片头 | 钩子后接品牌主标动效；片头不带某家公司/某期特有的数据 | 2.23 秒 |
| 女主持人提问 | 女头像在右侧高亮；男头像缩小弱化；对话卡只留一行问题 | 2 - 6 秒 |
| 男主持人回答 | 男头像在左侧高亮；女头像缩小弱化；数据面板是视觉中心 | 6 - 16 秒 |
| 章节标题卡 | 暗场/暗遮罩 + 章节编号与标题；只占转场空档 | 1.2 - 1.6 秒 |
| 收束与片尾 | 分析结论仍保持数据画面；最后一句才全屏切片尾 | 随末句，不额外拉长 |

### 人物与对话卡

- 1920×1080 画布下，发言头像固定 130×130、待场头像固定 64×64；位于画面上方左右角并作圆形面部裁切。沿用参考片红／青描边与发光，待场透明度 0.3；禁止大半身像。
- 对话卡在头像旁，但必须避开右上角栏目 Logo；不能与 Logo、人物脸部或标题重叠。它不是底部句级字幕的替代品。
- 对话卡只写 8 - 18 字的关键句。例如旁白讲研发费率、线控制动与验证节点时，对话卡只写：`Q3 主机厂定点，是兑现门槛`。
- 每条旁白切换到下一位时，再切人物高亮；不要让双人持续同时高亮。

![人物高亮、关键句与数据面板](assets/images/guide/03_active-speaker.png)

### 章节与数据出现顺序

1. 每个自然句可按语义停顿拆成多条独立短句 TTS，再使用**真实音频时长**写入 timeline；每条最多 28 字，拼接保持原文。不按字数估算、不把整镜音频按比例切分、不把音频硬拉长。
2. 为每段旁白标出“语义触发点”：提到第一个数字时出现第一张指标卡，提到验证点时出现第二项，讲因果时再出现曲线或说明。
3. 章节标题放在上一段结束后的自然空档内；若没有空档，可预留约 1.3 秒，用章节音效填充。
4. 章节卡完全淡出后，下一位人物和新数据面板才进入。**章节标题与人物对话不能同屏。**
5. 不要因为转场或默认片尾音效造成额外的 1 秒停顿。
6. `renderer/` 固定栏目视觉骨架和动效实现。本期由 Codex 选择组件、填写数据并绑定配音时间，不能复用历史节目内容，也不能每期重写人物、面板和导航。组件输入、容量、入场规则及不足时的处理见 [动效组件与内容适配说明](动效组件与内容适配说明.md)。
7. 逻辑章节可以跨多个确认分镜。人物观点用 `scene.summary`，底部摘要用 `chapter.summary`，底部小标题用 `chapter.label`，字幕用 `captions`；全片与单镜导出共用完整时间轴。

## TTS、背景音乐与音效：每期怎样选

下列是选型标准。TTS 音色使用当前获准配置或模板默认；背景音乐和音效默认使用上方的模板内置文件，只有明确替换时才重新选型。

| 类别 | 选择标准 | 使用与验收标准 |
| --- | --- | --- |
| 男声 TTS | 沉稳、自然、信息密度高时仍清晰的成年男声；避免播报腔、尾音拖沓、情绪过满 | 试听必须包含结论判断、百分比/专有名词、长句；适合解释、判断和结论 |
| 女声 TTS | 自然口语感强，有轻微交流感但不过度甜美或表演化；优先降低 AI 腔 | 试听必须包含短问题、追问、栏目收束句；与男声形成清晰的问答关系 |
| 背景音乐 | 默认：`assets/audio/bgm/immersed.mp3`；替换时保持无歌词、低存在感、轻科技/财经感、可循环 | 对白下约 10% - 14% 音量，开头 1 - 2 秒淡入；以对白优先，在章节/风险处可短暂再压低 |
| 章节音效 | 短促的扫光、界面切换或标题落定音；干净，不像游戏升级提示 | 一次章节最多两个声部：标题入场一次、落定一次；只填转场空档，不延长章节 |
| 数据音效 | 轻量 tick、计数或提示音；高频不刺耳、尾音不长 | 只配关键数字、指标卡、曲线的首次出现；同一镜头不要每个元素都响 |
| 风险提示音 | 单次、克制的提示/警示音；不选夸张警报或持续鸣叫 | 只在阈值、风险提示或警示结论出现时使用一次；不能遮住旁白关键词 |
| 片尾声音 | 优先用片尾主标动效内的短扫描/收束声；若另选，必须很短 | 与最后一句并行，不在说完后额外播放；旁白最后一帧即视频最后一帧 |

### 制作内声音自检

制作内抽查实际配音与混音，至少包含：

1. 男声的数字密集解释；
2. 女声的提问和追问；
3. 加背景音乐后的对白；
4. 一次章节切换、一次数据出现、一次风险提示；
5. 最后一句与片尾动效并行的收束。

Codex 自检中文咬字自然、男女声可区分、音乐不压词、音效不抢词；不增加外部试听确认。

## 导出前让 Codex 自检

- [ ] 逐条核对句级音频真实时长与 Sequence 起止帧；每句有底部字幕，无配音、字幕、动效提前或滞后。
- [ ] 任意时刻只突出一位人物；对话框不是完整旁白；Logo、头像、气泡卡不重叠。
- [ ] 发言头像 130×130、待场头像 64×64；中央面板为视觉主体，不出现大半身像。
- [ ] 底部章节摘要、小标题栏和红色全片进度条齐全；跨分镜不归零，标题随逻辑章节高亮。
- [ ] 字幕每条不超过 28 字，摘要和观点没有冒充完整字幕；无裁切或溢出。
- [ ] 所有数据、曲线、风险提示均按旁白递进出现，不能一进场全亮。
- [ ] 每个章节标题在说话前淡出，不能和人物卡同屏；章节没有无意义空白停顿。
- [ ] 片头不放本期业务数据；片尾从最后一句启动；女声结束时视频立即结束，没有尾音或空白。
- [ ] 对照参考片查看人物切换、章节转场、正文数据面板、底部导航和片尾静帧；同一动效至少检查入场前、中、后三帧并播放短片，不能用单张静帧判定动效合格。

## 一句话交付标准

观众应感觉是在看两位主持人围绕一份财报逐层追问：**谁说话谁突出；说到哪里数据就出现到哪里；章节和片尾都是节目节奏的一部分，而不是后贴上的模板。**
