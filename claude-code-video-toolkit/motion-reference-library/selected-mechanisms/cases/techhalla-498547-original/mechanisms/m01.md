# 字片错开沿竖向进入落稳后下线延长

## 运动指令

先建立首行，字片从竖向错开进入目标格位，正在进入的片保留可见经过，已到位的片停住。首行接近完整时启动下行，同样按次序落稳；下线沿横向延长，小标记跟随前缘建立。
