# 大图片保持局部短线与标签分次派生

## 运动指令

图片接入后保持取景，先在一个局部建立短标，从局部向空处延出细线并接标签。下一处按相同方法加入，已有标签保持；最后在图片空处补小前框，主行仍留在另一侧。

## 组合与调整

标签位置随新片局部决定；标线必须有明确起点，不把参考图片当新片素材。
