# 字片错峰移入转正后整行缩定

## 运动指令

让字片错开进入，部分片带倾角或较大尺度，接近基线时逐步转正。字行完整后整组稍缩到稳定范围，内部间距随之收好；下一短行可从原位置接替，旧行先退让。

## 组合与调整

字片可换几何片，不依赖原内容；入场和收势都落在同一基线。
