# 倾斜散条转正归队，再沿侧边连成纵列

## 运动指令

让分散且倾斜的条片各自移动到纵列位置，边移动边转正，使左右边逐步对齐；未归队的外围条片退去。排列基本成立后，从侧边建立竖线，再按行延长短支线接到条片，已连好的行保持。

## 组合与调整

可改变行数和间隔，但保留先归队后连接的关系。若直接接扫描，先给扫描留出清楚的首行位置，不要连线还未建立就跳过整列。
