# 点间局部传递，数值与尺度更新后突出一条分支

## 运动指令

在已有点群连接上让局部亮点或短反馈沿线推进，点内数值持续更新，主要点尺度逐渐增加。变化到稳定状态后只保留一条分支清楚，其他点和线退弱但位置保留。
