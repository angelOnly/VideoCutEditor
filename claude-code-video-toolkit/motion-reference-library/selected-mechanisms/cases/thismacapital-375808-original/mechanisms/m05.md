# 全幅收成并列竖片，圆层接管后缩为锚点

## 运动指令

将多个全幅各自收成并列竖片，集合建立后保持。圆形层从集合中部扩大接管，再缩回成小点，围绕小点建立标记与短行收尾。

## 组合与调整

圆形接管与收小是两个方向的动作，缩小后需给下一字组明确锚点。
