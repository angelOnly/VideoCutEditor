# 斜向带经过，后缘揭出下一全幅与字组

## 运动指令

让斜向宽带从边缘经过，先遮住旧层，再由后缘揭出新全幅。新层稳定后下方字组向上接入，后续按同一方向重复接替。

## 组合与调整

斜带宽度需覆盖交接，字组入场在新层可辨认之后。
