# 锁定局部逐级推近下一层承接再沿原路退回

## 运动指令

从完整结构中选定局部持续推近，旧边界逐步越界，内部下一层范围承接到相近中心。每一级保留少量旧层作为来源参照，再继续进入更细局部。末端稳定后沿相同层级反向后退，直到原整体恢复。
