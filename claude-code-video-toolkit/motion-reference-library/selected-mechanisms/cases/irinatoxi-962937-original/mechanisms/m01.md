# 从并置全貌锁定一片连续推入多级局部

## 运动指令

从双片全貌中锁定一片持续靠近，外框逐步越界，内部小组接管取景。再选择其中一个区块继续推入，更细的格阵和短杆逐级露出；每一级都保留少量上一层边界，中心来源连续。
