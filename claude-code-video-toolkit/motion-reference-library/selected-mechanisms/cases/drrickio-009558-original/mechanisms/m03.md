# 活动横框稳定，角落标签错开补入

## 运动指令

先保留横框内持续活动，再在上角、侧边、下角错开补入短标签。已经建立的标签保持，不让整框跟着每次补入抖动或重置。

## 分镜过程

![活动横框稳定，角落标签错开补入的分镜过程](m03.jpg)

## 组合与调整

可减少标签，必须避开活动重点；下一动作可整体退框，不逐项重复退出。
