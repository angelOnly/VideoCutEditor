# 柱状天际线

## 适用条件

比较类别大小，或在共同基线上呈现构成和总量。

当前横轴仍使用六个月份标记，而柱有18根；实际采用需先明确18项与时间的对应关系并更新标签。

## 实际怎样运动

- **初始画面：** 网格、坐标标签及适用图例已经存在，柱形从基线开始。
- **动作过程：** 18根柱按横向顺序错开从同一基线增长，柱高由示例公式计算。
- **关键中途：** 同一组的横坐标固定，柱高和堆叠基线共同求值，避免上层脱离下层。
- **完成状态：** 所有柱形到达目标高度，留下可比较的结果；没有额外的末段变形。

## 改哪些源码

入口为 [Scene.tsx](Scene.tsx)，所需绘制与基础依赖为 [cartesian.tsx](../../shared/cartesian.tsx)、[core.tsx](../../shared/core.tsx)。只读取当前分支和必要依赖。

## 如何用于本期

导演判断表达与前后衔接，美术判断造型、布局、运动中途和模板适配；候选不默认采用。将保留、修改或更换的结论写回同一份本期设计，必要时先试排。

采用后把所需源码移入本期工程。示例数值不是业务事实，数据、标签、图形和解释应共同更新。`time` 表示局部秒数；只对使用 `cue` 的动作传入 `cues` 才有效，其他动作需修改相应时间窗口。

`bare=true` 关闭参考样片包装，但不会自动缩放、重排或切换模板字体。按下载模板的实际创作区域调整布局和视觉，不改模板固定层，不回写共享库。对象、标签与连接共用位置依据。

根据本期真实配音安排开始、到达、强调和标签可读时刻，不拉长样例填满章节。最终在完整模板里播放实际片段，检查几何、阅读、声音接点与前后衔接。
