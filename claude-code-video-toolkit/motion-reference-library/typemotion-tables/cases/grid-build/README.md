# 网格搭建

## 适用条件

先建立表格秩序，再逐行转移注意。

固定三列四行；文字较长时先调整列宽。scan 的有效视觉结束早于其参数终点，勿按参数长度硬填静帧。

## 实际怎样运动

- **初始画面：** 表格线从左向右、从上向下建立；表头随 build 渐显。
- **动作过程：** 先延展网格与显露表头，再逐行填入数据；scan 期间浅色强调底在行间离散切换。
- **关键中途：** 行底色和该行文字共用行位置，网格位置独立定义；修改行高时需同步更新。
- **完成状态：** 最后一行保持强调，完整表格留存。

## 改哪些源码

入口为 [Scene.tsx](Scene.tsx)，所需绘制与基础依赖为 [matrix.tsx](../../shared/matrix.tsx)、[core.tsx](../../shared/core.tsx)。只读取当前分支和必要依赖。

Matrix 的 build/scan cues 控制建表与扫描；行 phase、names、读数数组、行高66及网格边界一起修改。

## 如何用于本期

导演判断表达与前后衔接，美术判断造型、布局、运动中途和模板适配；候选不默认采用。将保留、修改或更换的结论写回同一份本期设计，必要时先试排。

采用后把所需源码移入本期工程。示例数值不是业务事实，数据、标签、图形和解释应共同更新。`time` 表示局部秒数；只对使用 `cue` 的动作传入 `cues` 才有效，其他动作需修改相应时间窗口。

`bare=true` 关闭参考样片包装，但不会自动缩放、重排或切换模板字体。按下载模板的实际创作区域调整布局和视觉，不改模板固定层，不回写共享库。对象、标签与连接共用位置依据。

根据本期真实配音安排开始、到达、强调和标签可读时刻，不拉长样例填满章节。最终在完整模板里播放实际片段，检查几何、阅读、声音接点与前后衔接。
