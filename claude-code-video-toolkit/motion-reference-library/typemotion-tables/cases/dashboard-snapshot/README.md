# 仪表盘概览

## 适用条件

组织指标、趋势与解释，按观看优先级分阶段显露。

当前指标和折线路径分别写在分支内，不是统一数据驱动的仪表盘；换数据必须同步改图形与读数。

## 实际怎样运动

- **初始画面：** 标题和整体分区提供观看框架，主指标或图形尚未完成。
- **动作过程：** 五个分区交错从左右滑入并渐显；三项指标显露后，detail 同时画出趋势线并增长右侧四条指标条。
- **关键中途：** 不同分区使用固定坐标；数据与图形关联需在改写时共同维护，避免只更改数字。
- **完成状态：** 留下完整指标画面，后续内容有新关系时须继续设计，不能一直停在概览。

## 改哪些源码

入口为 [Scene.tsx](Scene.tsx)，所需绘制与基础依赖为 [dashboard.tsx](../../shared/dashboard.tsx)、[core.tsx](../../shared/core.tsx)。只读取当前分支和必要依赖。

Dashboard 的 kind 分支、cards、文字与数值数组及路径定义控制内容；build/detail cues 覆盖主要阶段，分区进场 phase 另行修改。

## 如何用于本期

导演判断表达与前后衔接，美术判断造型、布局、运动中途和模板适配；候选不默认采用。将保留、修改或更换的结论写回同一份本期设计，必要时先试排。

采用后把所需源码移入本期工程。示例数值不是业务事实，数据、标签、图形和解释应共同更新。`time` 表示局部秒数；只对使用 `cue` 的动作传入 `cues` 才有效，其他动作需修改相应时间窗口。

`bare=true` 关闭参考样片包装，但不会自动缩放、重排或切换模板字体。按下载模板的实际创作区域调整布局和视觉，不改模板固定层，不回写共享库。对象、标签与连接共用位置依据。

根据本期真实配音安排开始、到达、强调和标签可读时刻，不拉长样例填满章节。最终在完整模板里播放实际片段，检查几何、阅读、声音接点与前后衔接。
