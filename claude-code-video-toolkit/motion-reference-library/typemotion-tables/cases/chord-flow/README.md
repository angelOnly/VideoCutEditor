# 弦关系图

## 适用条件

表现多个类别之间的交叉连接；当前图强调连接存在，而非精确的流量比例。

当前弦带宽度为固定角度，不编码流量。连接太多会拥挤；不能把此例描述为沿线传递动画。

## 实际怎样运动

- **初始画面：** 六个外围弧段及标签依次显露，围绕同一中心布置。
- **动作过程：** 六条内部弦带错开渐显，逐步建立交织关系；弦带没有沿路径流动或动态拉伸。
- **关键中途：** 弦带端点与外圈弧段由 polar 共用中心、角度和半径计算；新增连接时保持外围标签可读。
- **完成状态：** 保留外圈定位与完整内部连接，适合接关系筛选或单条强调；这些后续动作需另写。

## 改哪些源码

入口为 [Scene.tsx](Scene.tsx)，所需绘制与基础依赖为 [relationships.tsx](../../shared/relationships.tsx)、[core.tsx](../../shared/core.tsx)。只读取当前分支和必要依赖。

Relationships 的 chord 分支中外围数量、连接对数组及 polar/arc 控制几何，phase 控制弧段和弦带显露。颜色来自 theme，标签来自 names。

## 如何用于本期

导演判断表达与前后衔接，美术判断造型、布局、运动中途和模板适配；候选不默认采用。将保留、修改或更换的结论写回同一份本期设计，必要时先试排。

采用后把所需源码移入本期工程。示例数值不是业务事实，数据、标签、图形和解释应共同更新。`time` 表示局部秒数；只对使用 `cue` 的动作传入 `cues` 才有效，其他动作需修改相应时间窗口。

`bare=true` 关闭参考样片包装，但不会自动缩放、重排或切换模板字体。按下载模板的实际创作区域调整布局和视觉，不改模板固定层，不回写共享库。对象、标签与连接共用位置依据。

根据本期真实配音安排开始、到达、强调和标签可读时刻，不拉长样例填满章节。最终在完整模板里播放实际片段，检查几何、阅读、声音接点与前后衔接。
