# 扇区揭示

## 适用条件

呈现构成占比或多个目标完成度；角度、半径与环长的含义取决于具体分支。

固定五类或三环；修改分类后要重新布置图例、配色和标签。数据含义必须与面积、角度或环长的映射相符。

## 实际怎样运动

- **初始画面：** 图形位于左侧，右侧为颜色对应的类别与数值；尚未完成展开。
- **动作过程：** 先逐个展开五个扇区，随后 focus 将第一扇区沿角平分线推出22单位，其百分数与图形一起位移。
- **关键中途：** 图例颜色与图形索引对应；外圈和中心读数不能因替换数据而失去一致含义。
- **完成状态：** 保留完整图形和图例，可接重点比较；样例未实现的强调需另写。

## 改哪些源码

入口为 [Scene.tsx](Scene.tsx)，所需绘制与基础依赖为 [radial.tsx](../../shared/radial.tsx)、[core.tsx](../../shared/core.tsx)。只读取当前分支和必要依赖。

Radial 的 vals、cx/cy、角度或半径、图例位置及数值数组控制画面；逐项 phase 在各分支内。build/focus 只对使用这些变量的分支有效。

## 如何用于本期

导演判断表达与前后衔接，美术判断造型、布局、运动中途和模板适配；候选不默认采用。将保留、修改或更换的结论写回同一份本期设计，必要时先试排。

采用后把所需源码移入本期工程。示例数值不是业务事实，数据、标签、图形和解释应共同更新。`time` 表示局部秒数；只对使用 `cue` 的动作传入 `cues` 才有效，其他动作需修改相应时间窗口。

`bare=true` 关闭参考样片包装，但不会自动缩放、重排或切换模板字体。按下载模板的实际创作区域调整布局和视觉，不改模板固定层，不回写共享库。对象、标签与连接共用位置依据。

根据本期真实配音安排开始、到达、强调和标签可读时刻，不拉长样例填满章节。最终在完整模板里播放实际片段，检查几何、阅读、声音接点与前后衔接。
