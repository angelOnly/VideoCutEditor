# 正文动效的项目适配

导演方法见 [directing-motion-art](../../directing-motion-art/SKILL.md)，美术与运动方法见 [motion-design-production](../../motion-design-production/SKILL.md)。本文件只处理当前工程接入和实际时间，不规定本期画面主体或布局。

## 当前模板与本期工程

先读取当前任务冻结模板的主说明、清单与包内引用，确认保护项、可编辑范围和可更新内容，并核对实际组件入口、坐标及字体。没有专门边界文件时结合已有说明和工程判断，不套用其他模板的头像、导航或正文容器。

本期组件只写任务副本；模板提供 visualExtensions 时注册组件及参数检查，否则使用当前工程已有入口。模板的固定包装与本期动态内容分别处理，不能以设计优化为由移除保护项，也不能把参考片全部内容锁定。

## 按真实口播安排时间

规划时使用语义触发点和动作时长范围。
配音完成后，依据真实utteranceId和音频窗口确定本次帧数。

只有句级边界时，就使用句级边界；
不能按字数推测某个词的准确发音时间。
已有有效音频优先复用；
新配音可按自然语义停顿拆短句，但不能改变确认稿。

每次动作的可用窗口，从相关口播触发点开始，
到下一视觉重点或图解实际可见区间结束之前截止，取最早者。
只有图解确实随镜头结束消失时，才以镜头结束为截止。
章节图解跨分镜导出时继续按章节时间执行，不因切成另一条MP4而截短。
不能把整个镜头剩余时间都交给一个入场动画。

动作时间是图形建立或有意义变化的时间；
读图停留是完整状态保留、观众阅读或听解释的时间；
无意义等待是相关口播已经开始，主体尚未建立，
或者画面只剩无关内容的时间。

动作完成后，口播仍在解释当前图形，可以稳定保留画面。
不要为持续运动而循环缩放、反复涨落或添加无关粒子。
下一事件未到来时保留仍有解释价值的状态，不提前清空。

窗口变短时，先取消装饰、减少顺序步骤、
合并可同时执行的动作；仍不足时使用更直接的完成状态。
不要把复杂动画压成难以看清的闪动。

窗口变长时，补充稿件中确实存在的解释阶段或保留读图状态，
不把简单入场拉长到整个窗口。
不得为满足建议时长插入静音、推迟口播或增加无意义尾部。

## 实现本期组件

在任务工程编写实际组件，按当前模板的接入方式使用。
模板提供visualExtensions时，通过它注册组件及参数检查；不要求其他模板提供同名入口。
组件接收本次已确定的触发点和动作时间，不自行猜口播。

使用已有实际时间轴，将语义触发点转换到组件的局部时间：先确认当前参数是全片、章节、分镜还是图解内部坐标，再减去该组件原点，只转换一次。保留源 utteranceId 与音频来源，窗口按实际可见范围裁定，动作时长不超过有效窗口。

为不同语义对象分别选对应 ID。时间可在构建 props 时派生或在组件中读取，
不要复制成互不关联的固定数字。需要稍提前建立背景或跨句连续运动时按内容设计，
并在审片中说明；不能让关键结论在讲解前已完成变化而无人检查。
跨镜章节按下文转换到章节/组件时间，不能直接沿用镜内时间。


所有状态由传入帧决定。
使用位置、尺寸、路径、角度、颜色和透明度计算画面，
不依赖浏览器实时动画。

统一时间坐标后再转换。以下仅适用于当前模板采用scene/chapter/visualBlock结构时；
其他工程使用自身已有的时间坐标，不为了套用示例重建模板：
全局帧=scene.from+镜内帧；
章节帧=全局帧-chapter.from；
组件帧=所属镜头或章节帧-block.startFrame。

扩展收到的frame已是组件局部帧，不再次减block.startFrame。
跨分镜章节图解不在每条MP4中重新从零播放。

区间不包含终点，最后可见帧为endFrameExclusive-1。
零时长变化直接显示完成状态，不构造起止相同的插值区间。

## 预览和修改

先看完整状态与关键转折静帧，再检查带真实配音的代表分镜。
对照原稿检查每次重要含义的推进，不能只检查已经写进代码的动作。
只有看图能力时，从实际候选抽取变化前、中、后及疑点相邻帧，结合真实配音时间核对；
如实记录观察范围，不把抽帧检查写成已经完整播放或试听。

拥挤：改对象数量、布局、标签和阶段。
看不懂：改对象和关系，不只增加装饰。
像文字幻灯片：重做承担信息的主要图形。
跳变：保留同一对象，用连续位置和尺寸变化连接。
节奏不符：改触发点、动作组合和完成时间。
栏目不统一：改字体、配色、线条、背景和强调方式。

修改本期工程后复查受影响段落。
静帧正常不能证明运动正常，导出成功不能证明设计完成。

## 正文最终状态、固定结束语与片尾

最后的实质结论仍属于正文，继续完成相应图解。
在正文实际结束位置留下完整可读的最终状态；
不提前清图、退场、淡黑或切Logo。

固定结束语期间保持这个正文视觉状态。
无需为了结束语另做图解，也不重复正文动效。
保持的范围不包含字幕和声音：结束语字幕正常更新，
固定结束语配音正常播放。

结束语来自栏目已选文本，时间取其实际音频记录，
不是按最后一句、角色或关键词推断。
全部口播结束后，由共享合成工具追加完整本地片尾；
片尾与结束语不重叠，不提前覆盖正文。

检查从最后正文到最终结束的带声音过程。
重点看正文最后状态是否完整、保持阶段字幕声音是否继续，
以及片尾是否在口播后从头完整播放一次。

## 实现与设计一致

每个主要视觉过程先在章节 brief 说明对象、入口、连续变化、中途、口播接点和出口。实现按这些过程组织状态，不按章节数量分配一张默认图。允许有依据的保持与文字主导强调；禁止用装饰循环冒充内容推进。

正式时间轴 visualDesign 是 brief 的执行索引，保存设计 ID、对应口播、change/hold、演出描述和实际实现位置。审片引用同一 ID；设计要求变化而实际保持时先修实现或明确修订设计，再重看，不能只改审片标签。结构校验不会判断画面美感，也不能证明观察真实。
