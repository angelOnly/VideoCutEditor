# 数据动画

先确定数值含义、单位、尺度和比较关系，再选择图形。
数据决定几何形状，动作进度只决定怎样从起点到达终点。

## 数值与几何

条形图先定义共同范围与零点，再把数值映射为长度。
同一比较的对象不能各自使用不同尺度。
占比使用固定整体尺度；零值保留标签或端点。

数字和几何使用同一进度，单位、精度和标签保持稳定。
避免数字位数变化导致整幅图跳动。

一般变化可以写成：
currentValue=fromValue+(toValue-fromValue)*progress。
再由currentValue计算长度、位置、面积或角度。
不能只更换终点数字而让图形不变。

## 前后变化与序列

只有前后两个值时，展示端点、同尺度条形或位置变化，
可保留弱化前值轮廓帮助比较。
不生成没有依据的中间年份、走势点或历史折线。

有真实序列时，按真实顺序和间距绘制。
路径揭示只显示已有数据，不生成新数据。

## 运动

组件接收本次起点与完成点。
起点前进度为0，完成后为1，在可见区间内达到完成状态。
起点与完成点相同的即时变化直接返回最终状态。

数值图形通常使用单调进度，不使用越过端点的弹簧。
多项启动顺序服从口播，不默认固定间隔轮流出现。

讲总量时突出总量；讲分项时展开分项；
讲差异时在共同尺度上突出差异。
不要求一开始显示所有图表。

## 完成状态与检查

变化结束后保留数值、单位、端点和必要说明。
后续仍解释当前结果时稳定展示；
出现新比较时再补充对象、切换重点或改变布局，
不反复播放同一次增长。

检查数值、来源、共同尺度、零值、标签、
数字与几何同步，以及是否越过真实端点。
检查带配音过程，确认结果不会刚出现就切走。

完整示例见assets/narrative-motion-examples.tsx中的数据变化示例。
示例是方法，不是所有视频固定使用的图表。

### 运行教学示例

将`assets/narrative-motion-examples.tsx`与同目录的
`narrative-motion-examples.entry.tsx`复制到当前任务工程，使用已有React和Remotion依赖。
以entry文件为渲染入口，Composition选择`NarrativeShort`或`NarrativeLong`，
规格分别为1280×720、30fps、54帧或162帧。
本地开发可用现有Remotion CLI执行
`remotion render 路径/narrative-motion-examples.entry.tsx NarrativeShort previews/narrative-short.mp4`；
Worker继续使用stage_media，不把教学数据或规格当作当前业务事实。
