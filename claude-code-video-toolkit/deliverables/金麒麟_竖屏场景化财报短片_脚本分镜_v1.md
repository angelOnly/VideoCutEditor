# 《财报揭秘室》竖屏场景化财报短片

## 金麒麟：利润跌 73%，为什么还在加码？

**版本**：策划与制作分镜 v1  
**成片规格**：1080 × 1920、9:16、30fps、约 2 分 55 秒  
**叙事形式**：单人解说 + 场景化数据动效；不使用双人头像作为主画面  
**本期核心问题**：利润承压时，金麒麟继续投入研发和产能，是提前卡位，还是给未来利润表埋雷？

---

## 1. 参考片风格如何转译为《财报揭秘室》

参考片的有效方法不是照搬它的字号或 IP，而是保留这套“问题驱动的解释语法”：

1. **一个问题贯穿全片**：开头抛出矛盾，底部固定保留问题，所有画面都在回答它。
2. **画面是解释器，不是背景**：每 2 - 5 秒更换一个微缩模型、档案画面、数据装置或手机界面。
3. **字幕只显示当前一句的结论**：不做逐字稿；每条控制在 6 - 16 字。
4. **从现象走向机制，再落到验证点**：反常数字 → 原因 → 风险条件 → 下一季要盯什么。

### 本片自己的视觉系统

- 外层：深蓝黑网格背景。
- 内层：圆角“财报档案”窗口，窗口标题固定为 `F.REPORT / 财报档案`，不使用参考片的名称、按钮或 Logo。
- 主视觉：以 **Remotion + SVG/CSS** 绘制数据装置、制动结构、工厂、资金管线、仪表与验证卡；局部以**品牌红、青、金**点亮重点数据。中文、数字和运动轨迹均由代码生成，可逐帧修改和校时。
- 窗口底部：白色结论字幕条。
- 画面底部固定锚点：

```text
财报档案 01
利润跌 73%，为什么还在加码？
财报揭秘室
```

- 栏目 Logo 只出现在固定锚点和片尾，不再使用人物头像、对话框、章节进度条。

## 2. 固定版式与节奏规则

| 区域 | 内容 | 规则 |
| --- | --- | --- |
| 顶部 10% | 档案窗口标题、三个品牌色状态点 | 全片固定，帮助形成系列识别 |
| 中部 55% | 场景化主视觉 | 只承载一个解释动作；每镜 2 - 5 秒 |
| 中下 10% | 单句结论字幕条 | 白底黑字，每句只保留一个可记住的结论 |
| 底部 20% | 固定问题锚点 + 栏目 Logo | 全片保持，不随镜头消失；片尾时关闭 |

### 动效节拍

- 一个关键数字出现，对应一次轻量数字 tick；不是每个字都响。
- 解释“转型”“资金来源”“转固”等机制时，用对象移动、分叉、点亮代替图表堆叠。
- 重点结论停留约 0.5 秒，让字幕和旁白同时落定。
- 每个新段落第一镜使用轻扫光/档案切页感转场；不能造成额外静音停顿。

## 3. 完整解说稿（单人旁白）

> 旁白以真实 TTS 音频时长为准。下文按约 2 分 50 秒节奏拆分；录音后必须用实际时长更新每个镜头的起止帧。

```text
营收降了 14.8%，净利润跌了 73.1%。

研发费用率却提高了 1.02 个百分点，
在建工程更涨了 139.6%。

利润几乎清零，钱为什么还在往研发和建厂里投？

金麒麟这份财报，真正要拆的不是利润为什么下滑，
而是这笔钱，能不能换回未来。

第一笔钱，是研发。
二季度研发费用率 4.32%。

传统液压制动，正在走向电子刹车和线控制动。
留给供应商切换产品路线的窗口，可能只有两到三年。

所以这笔钱，要么是下一代产品的门票，
要么只是给旧产品续命。

验证它的标准很简单：Q3 有没有主机厂定点。

有定点，研发才进入订单验证；
没有定点，回报周期可能继续拉长。

第二笔钱，是建厂。
在建工程期末 0.4 亿元，同比涨了 139.6%。

建厂不是为了下个季度的利润，
买的是 2027 到 2028 年的供给能力。

技术转型会淘汰落后产能，
活下来的龙头，才有机会拿到更多份额。

但扩产有一个前提：现金流要撑到需求回暖。

钱是来自自有现金，还是新增借款？
这比工厂建得多快更重要。

再看三张压力表。
固定资产周转率 1.53 次，处在正常区间下沿。

Capex 强度 65.6%，暂时还在安全范围；
存货营收比 44.8%，也没有越线。

可一旦工程转固，营收没有跟上，
Capex 就可能冲到 80% 以上。

折旧和闲置产能会一起压利润；
钢价下行，跌价准备也可能冒头。

所以 Q3 真正该盯的，不是一个利润数字。

而是五个信号：电子刹车定点与扩产、资金来源、
营收能否回到 4.5 亿元、转固时间，以及跌价准备。

它们决定这笔钱，是在提前卡位，
还是在给未来利润表埋雷。

财报揭秘室，把每一笔投入，拆成能验证的信号。
```

## 6. 声音与字幕执行规则

- 本片使用**一位**旁白；音色在正式生成前按“数字密集句、长句、收束句”各试听一次后确认。
- 背景音乐选择无歌词、低存在感、略有机械律动的氛围曲；对白下保持低音量，不能盖住数字。
- 音效按语义使用：数字出现用 tick、档案换页用扫光、风险越线用一次短促提示。禁止每个场景都加音效。
- 字幕不是逐字字幕，而是“结论标题”。每个镜头只出现一条，不超过两行。
- 数字读法与画面一致：`14.8%`、`73.1%`、`4.32%`、`0.4 亿元`、`139.6%`、`1.53 次`、`65.6%`、`44.8%`、`4.5 亿元`、`80%`。

## 本版不做什么

- 不使用双主持人头像和对话框。
- 不把所有财务数据一次性塞进面板。
- 不将此前横版片头或横版片尾直接裁切到竖版。
- 不照搬参考片的名称、按钮、配色或素材，仅借鉴“固定窗口 + 强问题 + 场景解释”的叙事方法。
