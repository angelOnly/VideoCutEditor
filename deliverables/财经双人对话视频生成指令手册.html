先读这一页：本片的“正确公式”

目标观感不是“念全文 + 静态 PPT”。而是：声音先行，数据/关键词随后出现；每次只突出一位主持人；章节与片尾都服务于节奏，不额外拖长。
模块已验证的做法不要这样做
开头先用 1 个问题或反差数据做钩子，再接 2.23 秒栏目片头。开场先放品牌片头，或一开始把所有数据抛完。
人物当前发言者 130px 高亮头像 + 一句关键结论；另一人 64px、低透明度。整段旁白塞进对话框，双方头像同等抢画面。
章节上一段结束后的 1.4 - 1.6 秒，先展示章节标题；标题退出后再进下一位人物。小标题与人物对话同时出现，或空白停 1 秒。
数据按照旁白中的数字、因果和验证点渐进出现。画面一进入就把全部卡片、折线和结论放完。
收尾最后女声“每期三分钟...”起，全屏主标动效；女声结束即终止视频。男声仍在分析时提前上片尾，或片尾后再加尾音/空白。

一、下次直接给 Codex 的两步式指令

步骤 A：先让它规划，不要直接渲染

我要做一支《财报揭秘室》风格的横版财经双人对话视频。请先不要生成视频，先阅读我提供的解读稿、人物头像、数据素材、音效和参考视频。

目标：约 [X] 分钟、1920×1080 / 30fps、16:9；不需要口型，只要头像与数据动效。
请输出：
1. 压缩后的完整男女对话文案（标明男女、每句的核心结论）；
2. 逐镜头分镜表：时间段、发言者、画面数据、关键句、音效、转场；
3. 每章节的标题卡位置与时长；
4. 片头/片尾如何接入现有动效；
5. 需要我确认的数字、音色和素材缺口。

节奏要求：钩子 → 片头 → 章节分析 → 全屏片尾；数据必须随旁白渐进出现；章节标题必须先出现并消失，再进入人物解说。

步骤 B：确认方案后，再让它执行

按已确认的分镜执行并渲染预览。使用豆包 TTS：男声“刘飞 2.0”、女声“流畅女声 2.0”。

人物规则：正在说话的人高亮放大；另一人缩小、弱化；对话卡只显示一句关键结论，不能直接放完整旁白。
音画规则：每条音频以真实时长写入 timeline；数据/卡片按句中信息分批出现；章节标题只占上一句结束后的转场空档；禁止标题和人物卡同屏。
片尾规则：最后女声“每期三分钟，拆解财报里的关键信号”开始时切入全屏主标动效，其他 UI 全部关闭；女声结束的同一帧结束视频，不加尾音、不留空白。

先输出 3 个关键时间点的静帧供我确认：一个人物切换、一个章节转场、一个片尾。确认后再导出完整 MP4。

三、固定镜头语法：如何排版才像“在对话”

镜头类型画面规则推荐时长
钩子单人提问 + 1 - 3 个反差指标；不先解释。8 - 15 秒
栏目片头钩子结束后接人物主标片头；无具体公司数据。2.23 秒
提问镜头女主持人右侧高亮；左侧男主持人弱化；只留一行问题。2 - 6 秒
回答镜头男主持人左侧高亮；右侧女主持人弱化；数据面板为视觉中心。6 - 16 秒
章节卡全屏暗遮罩 + 章节编号与标题；与声音错开。1.2 - 1.6 秒
收束男声说投资结论时仍是分析画面；最后女声开始时切全屏品牌片尾。3 - 4 秒（仅随末句）
对话卡写法把整段旁白“压缩”为 8 - 18 字的关键句。例如旁白讲研发费率、线控制动和验证节点；对话卡只写“Q3 主机厂定点，是兑现门槛”。

四、章节与音画同步：这一步决定视频是否“专业”

  1. 将每条 TTS 音频的真实时长写入 timeline；不要按文字字数估算。
  2. 给每段旁白定义“语义触发点”：讲到第一个数字再出现第一张卡；讲到第二个验证点再出现第二项。
  3. 章节卡放入上一段结束后的已有停顿；如果没有自然停顿，预留约 1.3 秒，并由章节扫光音效填充。
  4. 章节卡最后一帧必须先消失；下一条音频第一帧才出现发言者高亮卡。
  5. 不要对整段音频做拉伸，也不要在视频最后添加“默认收尾音”。

七、交付前验收清单（让 Codex 自检）

  • 逐条核对音频时长与 Sequence 起止帧，确认没有配音、字幕、动效提前或滞后。
  • 任意时刻只突出一位发言者；对方仅保留弱化头像。
  • 对话卡只显示关键句，不显示整段旁白。
  • 右上角栏目 Logo 与人物头像、气泡卡保持安全间距。
  • 章节标题在说话前完成淡出，不能和人物卡重叠。
  • 所有数据卡、曲线和风险提示按旁白递进出现，不能一进场全亮。
  • 片头不放具体公司数据；片尾从最后一句启动，片尾结束不再加音效或空白。
  • 至少导出并人工查看：人物切换、章节卡、片尾三个关键静帧，再导出成片。
一句话交付标准观众应该感觉是在看两位主持人围绕一份财报逐层追问：谁说话谁突出；说到哪里数据就出现到哪里；章节和片尾都像节目节奏的一部分，而不是后贴上的模板。
